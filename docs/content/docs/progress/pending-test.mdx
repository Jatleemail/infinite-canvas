# 待测试

- 画布助手 Agent 模式：对话模式右下角默认启用紫色 ⚡ Agent 开关；切到一个支持 tool calling 的模型（GPT-4o / Claude / qwen3.7-max 等），对助手说"把当前选中的图片排成一行"应能看到执行中的工具卡片（"调整布局 执行中..."）→ "已按 horizontal 布局重排 N 个节点"，画布上节点按水平排列。已用 qwen3.7-max 验证多步组合 "添加 3 个文本节点 A/B/C → get_canvas_summary → 把所有文本节点排成 horizontal 一行" 全链路可用，工具调用卡片正确渲染。其他可验证场景：1) "添加一条文本说明：xxx" 应调 add_text_node；2) "把 n_a1 和 n_a2 连起来" 应调 add_connection；3) "选中所有图像节点" 应调 select_nodes；4) "把所有图像节点排成 2x2 网格"。Agent 关闭后回退为纯流式回答。模型不支持 tools 时也应保持可用（流式回答即可）。
- 画布助手"视频"模式：在助手面板下方模式切换里点"视频"，模型选择器切到 video 候选模型；不选节点直接输入"一只在月球散步的猫"应能生成视频，结果在助手消息内带 `<video controls>` 预览并可点"+"插入画布为视频节点；选中 1-7 张图像节点作为参考时应走图生视频；选中视频/音频节点会被忽略并提示。需要分别用 OpenAI grok-imagine-video 和 Seedance 视频模型验证生成、插入、错误提示（API Key 失效 / 超时）。
- 画布助手"音频"模式：模型切到 audio 候选；输入文本生成 TTS，助手消息内带 `<audio controls>` 预览并可一键插入画布为音频节点；语音、格式、速度等设置仍由 effectiveConfig 提供。需要在 OpenAI gpt-4o-mini-tts 和 Vidu 音频模型下分别验证。
- 画布助手面板移除"未开发"标签：错误回复改为红色错误样式且保留"重试"按钮；按 Ctrl/Cmd + I 可在 textarea 之外的画布区域打开/收起助手，且快捷键已登记到画布快捷键弹窗。
- 画布助手对话模式（"对话"）会自动注入画布概览作为系统消息，包含节点编号（n_a1 / n_t1 ...）、类型分布、节点 prompt/内容/尺寸等元数据摘要、连线列表和当前选中。需要在不选中任何节点直接提问"我画布里有几张图、prompt 都讲了什么"以及选中某节点提问其上下游关系两种场景验证助手回答准确；选中视频/音频节点应在输入框上方提示"已忽略 N 个视频/音频节点（暂不支持作为参考）"。
- 云端渠道新增"默认音频模型"和 Vidu 协议语音合成：管理员在 `/admin/settings` → 私有配置新增协议为 Vidu 的渠道（`https://api.vidu.cn` + `vda_...` API Key）并把 `vidu-audio-tts` 加进 `models`；公开配置中可选"默认音频模型"为 `vidu-audio-tts` 并配置算力点；用户在画布音频节点底部音频设置面板中，识别到当前模型为 Vidu 音频模型时，"声音"下拉切换为 Vidu 内置音色清单（男声/女声/童声/角色音/粤语分组共 60+ 项）、格式提示固定 MP3、隐藏 OpenAI 风格的"声音指令"；后端 `/audio/speech` 在选到 Vidu 协议渠道时会调用 Vidu `/ent/v2/audio-tts` 同步合成、必要时短轮询 `/ent/v2/tasks` 拿到 `file_url` 后下载音频字节流回写为 `audio/mpeg`。需要验证：1) 管理员后台保存"默认音频模型"后前端 `useEffectiveConfig` 能拉取到该默认值；2) 选中 Vidu 模型时前端音色下拉正确切换且选项可点；3) 端到端用 Vidu 音色生成音频节点成功，音频可播放/下载；4) Vidu API Key 失效或文本超过 10000 字时积分能正确退还且错误信息可读。
- 云端渠道新增 Vidu 协议（`viduq2` 生图）：管理员在 `/admin/settings` → 私有配置新增协议为 Vidu 的渠道，填入 `https://api.vidu.cn` 和 `vda_...` API Key，模型加入 `viduq2`，再把公开配置的”默认图片模型”设为 `viduq2` 并配置算力点；用户侧云端渠道模式下发起生图和图生图（带参考图）请求时，后端会创建 Vidu 任务、轮询 `/ent/v2/tasks` 直到完成、下载 PNG 并以 `b64_json` 形式返回，前端无需改动；需要验证文生图、图生图、超时（最长 180s）和无效 API Key 时积分能正确退还。
- 云端渠道 Vidu 协议支持视频生成：在已有 Vidu 渠道的 `models` 列表里追加 `viduq2-pro`、`viduq2-turbo` 等视频模型并配置算力点，把”默认视频模型”设为 `viduq2-pro`；画布上选 1 张参考图触发 `viduq2-pro` 应走 `/ent/v2/img2video`、连 2-3 张图应走 `/ent/v2/multiframe` 且按总时长均摊到每段 2-7 秒、把默认模型临时改为 `viduq3-pro` 后再触发多图应在服务端日志看到”自动降级到 viduq2-pro”且仍能成功；连参考视频或参考音频给 Vidu 视频模型应被拒绝且积分退还；后端会按选定模型钳 `duration`（q3 1-16 / q2 1-10 / q1 固定 5 / vidu2.0 4 或 8）与 `resolution`（q1 强制 1080p / vidu2.0 8s 强制 720p / 其余 540p/720p/1080p）。
- 视频创作台创建视频任务成功后会立即写入左侧生成记录，状态显示为”生成中”；刷新页面后会读取本地任务 ID 继续轮询，任务成功或失败后更新同一条记录，需要验证 OpenAI 视频接口和 Seedance 任务接口的刷新恢复。
- 修复画布文字节点编辑时双击进入编辑、全选文本出现重影和错位的问题；文字节点内容编辑框改为使用原生 textarea 文本渲染，仍保留 `@` 资源候选插入，需要验证编辑态选区、展示态文字换行和右上角“生图”按钮避让都正常。
